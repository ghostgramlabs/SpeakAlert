# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through GitHub:
**Security** tab > **Report a vulnerability** on
[github.com/ghostgramlabs/SpeakAlert](https://github.com/ghostgramlabs/SpeakAlert/security/advisories/new).

Include the steps to reproduce, the affected version, and the impact you expect. We will
acknowledge the report and keep you updated while we work on a fix.

## Supported versions

Only the latest version published on Google Play receives security fixes.
